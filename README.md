# Cierre de Operaciones

Prototipo visual (React + Vite) del tablero de **cierre diario de beneficio** y **novedades de personal**, con alcance **2026+**.

## Módulos

**Visualizar**
- Inicio
- Simulación
- Cierre de proceso
- Consolidado
- Novedades

**Capturar**
- Base de datos cierre (formulario que alimentará el resto)

## Desarrollo

```bash
npm install
npm run dev
```

## Notas

- Datos actuales: mock local (`src/data/mock`).
- Persistencia: memoria del navegador (store React).
- Base de datos real: pendiente en servidor externo.
